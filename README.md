# Le Donjeon — lanceur de dés et gestionnaire de combat

Page en ligne : https://undrwrldream.github.io/ledongeon/

- Le MJ ouvre la page et touche **👑 Je suis le MJ** : il obtient un code et un lien de partie à partager.
- Les joueurs ouvrent ce lien et choisissent leur héros.
- La page du MJ doit rester ouverte pendant toute la partie : c'est elle qui lance les dés et fait jouer les monstres.
